Laboratorium Perangkat Keras

Alur Kerja & Integrasi Sistem Tersemat

Bagaimana sinyal analog dari sensor dikonversi menjadi data analitik yang berguna pada dashboard web.

01

Akuisisi Sinyal

Pembacaan sensor analog dan digital (I2C, SPI, UART, ADC 12-bit) dengan filtering tegangan stabil.

DHT22, PZEM, BME280
02

Komputasi Tepi (Edge)

Pengolahan awal data di mikrokontroler, kalibrasi offset, dan kompresi payload JSON sebelum transmisi.

ESP32, STM32, Arduino C++
03

Protokol Transmisi

Pengiriman paket data hemat daya dengan protokol ringan melalui konektivitas WiFi, GSM, atau LoRa.

MQTT, WebSockets, REST
04

Penyajian Web

Visualisasi grafik responsif, penanganan peringatan abnormalitas, dan kendali relay dua arah.

HTML5, Canvas, DOM API
